## AI 자유 행동

기존 버튼으로 플레이하거나, AI 자유 행동 입력창에 지용이가 할 행동을 직접 입력할 수 있습니다. 실행 후 실제 행동 결과, 능력치 변화, 랜덤 이벤트와 AI의 짧은 이야기를 표시합니다. Ctrl+Enter 또는 실행 버튼을 사용하세요.

- 모델: [SmolLM-135M-Instruct ONNX](https://huggingface.co/HuggingFaceTB/SmolLM-135M-Instruct), 리비전 `fcc320f490e08fdb4b99d935b2c58d40bf35b0d0` 고정.
- 실행: Transformers.js 3.8.1, q8 양자화, Web Worker 안에서 WASM 단일 스레드로 추론합니다. WebGPU나 서버, API 키가 필요하지 않습니다.
- 첫 실행에 약 137MB의 모델 가중치, 토크나이저와 WASM 실행 파일을 다운로드합니다. 지원되는 브라우저에서는 다운로드 파일을 캐시합니다. 실제 메모리 사용량은 다운로드 크기보다 큽니다.
- CDN과 Hugging Face에는 실행 파일과 모델 다운로드 요청만 보냅니다. 입력 내용과 게임 상태를 추론 서버로 보내지 않습니다.
- 작은 영어 중심 모델이므로 한국어가 어색하거나 영어로 답할 수 있습니다. 모델의 서술보다 화면의 **실제 결과 / 능력치 변화**가 기준입니다.

`잠자기`, `씻기`, `공부`, `단련`, `휴식`, `장보기`, `로동`, `구걸`, `쌀국수 먹기`, `돌밥 먹기` 등 등록된 표현은 기존 게임 함수를 실행합니다. `로동`은 탄광 노동을 뜻합니다. 식사는 각각 50원 / 5원이 있어야 실행합니다. 한 번에 한 행동을 입력하세요.

이 외의 입력(예: `산책하면서 노래하기`)은 자유 행동으로 처리합니다. 자유 행동은 에너지를 최대 5만큼 소모(최소 0), 행복 +3, 1턴 진행을 적용하며 기존의 턴 소비와 랜덤 이벤트가 함께 발생합니다. AI가 임의의 수치나 보상을 실행하지는 않습니다. 입력과 생성 문장은 HTML이 아닌 일반 텍스트로만 표시합니다.

다운로드 중 실패하거나 중지하면 행동/턴을 소비하지 않습니다. 행동 처리 후 AI 설명이 실패하거나 중지되면 이미 적용한 실제 결과를 그대로 남깁니다. 처리 중에는 다른 게임 버튼과 중복 실행을 잠그며, 진행 중인 결투는 기존 버튼으로 마쳐야 합니다. 게임 오버 시에도 결과를 확인하고 **새 인생 시작** 버튼으로 재시작할 수 있습니다.

## 실행

빌드가 필요 없는 정적 사이트입니다. `index.html`, `ai.js`, `ai-worker.js`를 함께 호스팅하세요. HTTPS 또는 localhost로 접속해야 합니다. 파일을 직접 여는 `file://` 방식에서는 AI를 사용할 수 없습니다.

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 여세요. 초기 다운로드를 위해 jsDelivr와 Hugging Face 및 모델 다운로드 CDN에 접근할 수 있어야 합니다. WASM은 단일 스레드여서 GitHub Pages에서도 별도 COOP/COEP 헤더가 필요하지 않습니다.

## 검증

Node.js 20 이상에서:

```sh
npm ci
npm test
```

기본 테스트는 jsdom과 모델 모의 구현으로 실제 게임 코드, AI UI 코드, Worker 핸들러를 실행합니다. 실제 모델 다운로드/추론 품질이나 브라우저 레이아웃을 검증하는 테스트는 아닙니다. 기존 행동, 자유 입력, XSS 방지, 다운로드/추론 오류, 취소, 재시도, 중복 제출, 게임 오버 및 이벤트 기록을 검사합니다.

선택적으로 Chromium에서 모델을 모의한 브라우저 테스트도 실행할 수 있습니다.

```sh
npx playwright install chromium
npm run test:browser
```

실제 모델 확인은 브라우저에서 입력을 제출한 뒤 모델 다운로드가 끝나고 **AI 이야기**와 `완료 · 이 브라우저에서 SmolLM 135M으로 생성했습니다.` 메시지가 나타나는지 확인하세요. 오류가 발생하면 실제 결과를 유지하며 다시 시도할 수 있습니다.
